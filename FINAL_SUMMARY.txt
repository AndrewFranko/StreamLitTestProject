PIPELINE OVERVIEW
================================================================================

FLOW:
  Developer Push
       ↓
  Build Job (GitHub Hosted)
  - Checkout code
  - Setup Python 3.10
  - Install dependencies
  - Validate syntax
  - Create artifacts
  (2-3 minutes)
       ↓
  Test Job (GitHub Hosted) [Depends on Build]
  - Download artifacts
  - Run linting (flake8)
  - Check formatting (black)
  - Validate imports (isort)
  - Run tests (pytest)
  - Upload reports
  (2-3 minutes)
       ↓
  Deploy Job (Self-Hosted) [Depends on Test]
  - Download artifacts
  - Install on target
  - Stop previous instances
  - Deploy Streamlit app
  - Verify health
  - Check logs
  (2-3 minutes)
       ↓
  Notification Job [Always runs]
  - Report pipeline status
       ↓
  APPLICATION RUNNING (Port 8501)

TOTAL TIME: 7-9 minutes from push to deployment

KEY FEATURES
================================================================================

✅ GitHub Hosted Runners
   • Build and Test run on ubuntu-latest
   • No infrastructure setup needed
   • Automatic cleanup

✅ Self-Hosted Runner Support
   • Deploy runs on target machine
   • Full control over environment
   • Supports local, VM, and cloud

✅ Job Dependencies
   • Test only runs after Build succeeds
   • Deploy only runs after Test succeeds
   • Prevents bad code from deploying

✅ Build Artifacts
   • Source code uploaded after Build
   • Transferred between jobs
   • Available for download

✅ Comprehensive Validation
   • Python syntax validation
   • Code linting (flake8)
   • Format checking (black)
   • Import ordering (isort)
   • Unit tests (pytest)
   • Module imports

✅ Deployment Verification
   • HTTP health checks with retries
   • Log file inspection
   • Process monitoring
   • Automatic error reporting

✅ Conditional Execution
   • Deploy only on main branch
   • Deploy only on push (not PR)
   • Prevent accidental deployments

GETTING STARTED (5 STEPS)
================================================================================

1. SETUP RUNNER (5 minutes)

   Linux/macOS:
   $ bash setup-runner.sh

   Windows (Run as Admin):
   > .\setup-runner.ps1

   Follow prompts:
   - Enter GitHub repo URL
   - Enter Personal Access Token (PAT)
   - Enter runner name (or use default)

2. VERIFY RUNNER ONLINE

   Go to: Settings → Actions → Runners
   Status: "Online" (green dot)

3. TRIGGER PIPELINE

   $ git push origin main

4. MONITOR EXECUTION

   Go to: Actions tab
   Watch: Build → Test → Deploy (7-9 min)

5. ACCESS APPLICATION

   Browser: http://localhost:8501

   Or:

   curl http://localhost:8501

TROUBLESHOOTING QUICK REFERENCE
================================================================================

PROBLEM: Runner shows "Offline"
SOLUTION: Run setup script again
          Or: sudo systemctl restart github-runner

PROBLEM: Build fails
SOLUTION: Check Python version (need 3.10+)
          Run: python --version

PROBLEM: Deploy fails with port error
SOLUTION: Kill existing process
          Linux: pkill -f streamlit
          Windows: taskkill /F /IM python.exe

PROBLEM: Application not responding
SOLUTION: Check logs
          Run: tail -f logs/app.log

          Or verify:
          Run: bash verify-deployment.sh

For more help:
  See GITHUB_ACTIONS_SETUP.md (Troubleshooting section)
  Or QUICKSTART_CICD.md (Troubleshooting table)
