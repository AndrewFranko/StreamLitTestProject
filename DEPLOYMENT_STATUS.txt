SECTION 9: TROUBLESHOOTING CHECKLIST
================================================================================

Issue: "ModuleNotFoundError: No module named 'streamlit'"
Fix:
  1. Run: pip install streamlit
  2. Or run startup script which auto-installs

Issue: "GOOGLE_API_KEY not found"
Fix:
  1. Verify .env exists at c:\StreamLit\.env
  2. Check key is present: cat .env
  3. No quotes around key value
  4. Restart Streamlit after fixing

Issue: "FileNotFoundError: machines.json not found"
Fix:
  1. Verify files exist: ls -la src/data/
  2. Check JSON syntax: python -m json.tool src/data/machines.json
  3. Check file permissions (should be readable)

Issue: "Port 8501 already in use"
Fix:
  streamlit run src/ui/app.py --server.port 8502

Issue: "Agent not responding or slow"
Fix:
  1. Check internet connection
  2. Verify API key is valid
  3. Check Gemini API quota
  4. Restart Streamlit server
