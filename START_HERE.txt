QUICK START (WINDOWS)
================================================================================

1. Open Command Prompt
   - Press Windows + R
   - Type: cmd
   - Press Enter

2. Navigate to the project
   cd c:\StreamLit

3. Run the startup script
   run.bat

4. Wait for this message to appear
   "Local URL: http://localhost:8501"

5. Open your browser and go to
   http://localhost:8501

6. You're done! Start chatting with the AI assistant.

================================================================================
WHAT YOU CAN DO
================================================================================

The application has 4 different AI personas, each designed for different users:

1. OPERATOR (for machine operators)
   - Get quick answers about error codes
   - Learn safe operating procedures
   - Report issues to maintenance
   Example: "What does error E17 mean?"

2. ENGINEER (for maintenance technicians)
   - Get detailed diagnostic procedures
   - Understand root causes of problems
   - Get parts and specifications
   Example: "How do I fix machine MX-204?"

3. SUPERVISOR (for production supervisors)
   - Check real-time machine status
   - Track downtime and production impact
   - Coordinate maintenance resources
   Example: "Are technicians available right now?"

4. MANAGER (for plant managers)
   - Get strategic operational insights
   - View plant-wide KPIs and trends
   - Get optimization recommendations
   Example: "What's our plant status today?"

To switch roles: Use the dropdown menu in the left sidebar

KEY FEATURES
================================================================================

Role-Based AI Responses
  The AI changes its personality based on your selected role.
  Operators get simple answers. Engineers get technical details.

Tool-Powered Intelligence
  The AI can:
  - Check machine status and history
  - Explain what errors mean
  - Find available technicians
  - Create maintenance work orders

Human Approval for Critical Actions
  When you ask to create a maintenance ticket, you get to approve it first.
  This prevents accidental ticket creation.

Chat History
  Each conversation is saved in the current session.
  History clears when you switch roles.

================================================================================
TROUBLESHOOTING
================================================================================

Q: Nothing happens when I click Send
A: The AI is processing. Give it 3-5 seconds. Slower networks may take longer.

Q: "Port 8501 already in use" error
A: Another app is using that port. Run on a different port:
   streamlit run src/ui/app.py --server.port 8502

Q: "Module not found" errors
A: The startup script should install everything. If not:
   pip install -r requirements.txt

Q: API key errors
A: Your .env file should have the GOOGLE_API_KEY. Check that it exists.

Q: App won't start
A: Make sure Python 3.10+ is installed:
   python --version

   Install from: https://www.python.org

Q: Page is blank or won't load
A: Hard refresh your browser:
   Windows: Ctrl + Shift + R
   Mac: Cmd + Shift + R

================================================================================
STOPPING THE APPLICATION
================================================================================

To stop the Streamlit server:

1. Go back to the Command Prompt / Terminal where it's running
2. Press Ctrl + C
3. Type Y to confirm

The web interface will stop responding after this.

To restart, just run the startup script again.
