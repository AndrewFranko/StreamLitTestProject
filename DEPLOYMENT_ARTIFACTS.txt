TOOLS AVAILABLE IN LEVEL 2
================================================================================

1. check_machine_status(machine_id)
   - Get real-time status of a machine
   - Returns: name, status, last maintenance, current error codes
   - Example: check_machine_status("MX-204")

2. lookup_error_code(error_code)
   - Get meaning and recommended action for error codes
   - Returns: error name, severity, description, recommended fix
   - Example: lookup_error_code("E17")

3. create_maintenance_ticket(machine_id, description, priority)
   - Create a maintenance request ticket
   - Requires human approval before submission
   - Returns: ticket ID, confirmation message
   - Example: create_maintenance_ticket("MX-204", "pump seal replacement", "high")

4. check_technician_availability(specialty)
   - Check available technicians by specialty
   - Returns: list of technicians, workload, availability time
   - Example: check_technician_availability("hydraulics")

HOW TO GET GEMINI API KEY
================================================================================

1. Visit: https://makersuite.google.com/app/apikey
2. Sign in with Google account (create if needed)
3. Click "Create API key" button
4. Select "Create API key in new project"
5. Copy the generated key (starts with AIza...)
6. Add to .env file: GOOGLE_API_KEY=AIza...
7. Keep secret - never commit to git

TROUBLESHOOTING QUICK REFERENCE
================================================================================

Issue: GOOGLE_API_KEY not found
  → Add key to .env file
  → Check .env exists: ls -la .env
  → Verify key: grep GOOGLE_API_KEY .env

Issue: ModuleNotFoundError: langchain
  → Activate venv first
  → Reinstall: pip install -r requirements.txt --force-reinstall

Issue: API_KEY_INVALID or 401 Unauthorized
  → Verify key at https://makersuite.google.com/app/apikey
  → Regenerate if needed
  → Restart Streamlit (Ctrl+C, then rerun)

Issue: Port 8501 already in use
  → streamlit run src/ui/streamlit_app.py --server.port 8502

Issue: Slow responses greater than 10 seconds
  → First request is slower (model loading) - wait up to 10s
  → Check internet connection
  → Subsequent requests: 2-3 seconds

Issue: Tool calls fail
  → Check data files exist: data/machines.json, etc.
  → Verify JSON syntax
  → Enable debug mode in Streamlit sidebar
